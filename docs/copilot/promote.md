# Promote

Use this workflow when deciding whether a `next` line should become `now`, or whether a `now` line should be parked.

Inspect evidence, unresolved uncertainty, opportunity cost, and the likely value of further attention. Explain the trade-off and the conditions that would change the recommendation.

Do not treat age, activity, or file completeness as sufficient reasons to promote or park.

The recommendation is advisory. An explicit user instruction to change state authorizes the mutation.
