# Capture

1. Read `SKILL.md`.
2. Inspect `research/*.md` before proposing a new line.
3. Classify the incoming signal as evidence for an existing line, a candidate new investigation, or nothing.
4. Preserve provenance: confirmed evidence, user assertion, inference, or hypothesis.
5. If an existing line fits, propose how the signal updates that line. If the user explicitly asks to record it, execute the update.
6. If no line fits and the signal appears worthy of attention, propose a new research line. Do not create it merely from novelty.
7. It is valid to conclude that the signal does not earn roadmap space.

Capture optimizes consolidation and low friction, not completeness.
